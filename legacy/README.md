# Preserved prototype source

These files preserve the original browser-only UI, MediaPipe/Whisper experiments, IndexedDB history and telemetry analysis for reference. They are **not imported, built, linted or deployed** by the current application. Their obsolete dependencies have been removed from the active package manifest. Use git history to run the original prototype with its original dependencies.

Do not restore the old browser API-key storage, random follow-up fallback, unsupported landing claims, forced camera/fullscreen, or face-derived content scores. Existing IndexedDB data is left untouched in users' browsers; it is not imported as semantic answer evaluation. The active application is src/product and server/.
